# 认知简报 = 藏宝图（设计提案）

> 概念图：[`treasure-map-concept.svg`](./treasure-map-concept.svg)（本目录，可直接浏览器打开）
> 状态：提案（方向待用户/协作者裁定后进入 V1 实现）

## 一句话

藏宝图不是新数据，而是**同一套派生的航海叙事皮肤**：工作树的河流系统换上皮，
再叠加灯塔、雾块、漂流瓶三个已有数据的图层。全部元素来自真实账本，零排名、零劝告。

## 映射表（数据源全部现成）

| Mimir 概念 | 地图元素 | 数据源 |
|---|---|---|
| 项目（研究领地） | 岛屿 | `projects` |
| 主线 | 大河干流（最粗）＋赭石虚线路线（reflog） | worktree mainline / mainlineHistory |
| 研究线（想法） | 支流；宣告派生 = 分叉 | worktree lanes + 声明的 parent 边 |
| 并入（merge） | 汇流处一只**打开的宝箱** | `status: adopted` |
| 死巷（有据的 No） | **干涸河床 + 暗礁 ✕ + 教训碑**（那句 No 的理由） | `status: failed` + closeReason |
| 工作节点 | 沿河**足迹珠子**（终局＞创造＞日常＞轻触；悬停显示动作） | worktree touches |
| 已证实断言 | **灯塔**（照亮一片水域） | claims `supported` |
| 被证伪断言 | 沉船 | claims `invalidated` |
| 宣告未开垦 | **雾块**（虚线轮廓；雾 = 没有事件 ≠ 没有前景） | foraging 安静领地 |
| 主线宣告史 | **罗盘玫瑰**（每次宣告 = 一次转向） | mainlineHistory |
| 手记 | **漂流瓶**锚定在发生时刻 | journal（L2） |
| 线状态 | 河流地貌：丰水干流 / 死水潭 / 汇聚 / 蜿蜒新汊 / 回湾 | brief DDM-lite 状态 |

## 设计语言

- **老羊皮纸**：径向渐变纸底 + 细颗粒噪点（feTurbulence），暖米/赭/褐墨三色系。
- **雕刻双线**：河流先铺墨晕再压水色芯，版画质感；海岸线加手绘抖动位移滤镜。
- **零文字地图**（正式版）：状态由形状与颜色表达；名字、日期、数字在悬停卡片与图例。
  概念图中的题匾/罗盘 N/图例为例外面向人的装饰，不进入数据层。
- **图框 + 题匾 + 罗盘 + 比例尺**：经典制图四件套，比例尺直接承担「压缩时间」的诚实声明。

## 分阶段落地

- **V1 单岛图**：现有 branch-flow 布局引擎换河流皮肤 + 雾/灯塔/漂流瓶叠加层。
  纯客户端组合 `getWorktree + getForaging + getBrief`，不动服务端。
- **V2 群岛与回放**：跨项目 = 群岛 + 航线；时间回放滑杆（派生是纯函数，
  支持任意 asOf 重推——「重走一遍探索路」）。
- **V3 一图导出**：导出单页 SVG/PNG 分享。

## 诚实规则（进宪法）

1. 只画**宣告过的**结构（派生边、主线、并入、关闭），绝不推断。
2. 宝箱只开在事实上（并入/断言裁定），不评分、不喝彩。
3. 雾 = 无事件 ≠ 无前景。
4. 压缩刻度必须声明（比例尺），真实数字留在卡片与列表。
5. 地图零动词：它永远不说「去这里挖」，只说「你走过的路在这里」。
