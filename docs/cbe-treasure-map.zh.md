# 认知简报 = 探索路径图（设计提案 v2）

> 概念图：[`treasure-map-concept.svg`](./treasure-map-concept.svg)
> 状态：提案 v2（2026-08-27 重设计——v1 羊皮纸插画方向被否：过度图例违反极简与第一性原理，具象卡通配不上科研 UI）

## 一句话

「藏宝图」不是插画风格，而是**探索路径的拓扑**：一条主轴、分叉、汇流、终点、裁定。
全部元素来自真实账本派生，零排名、零劝告、零图例。

## 极简五原则（本轮反馈固化）

1. **数据即图形**：图上不存在非数据元素。无罗盘、无题匾、无图框、无装饰。
2. **形状词汇 ≤ 4**：线（研究线，粗=主线）、点（工作节点）、✕（死巷终点）、菱形（断言裁定）；汇流用实心点。不再引入新形状。
3. **颜色 ≤ 3**：暖白底 / 暖灰中性（一切支线）/ 单一强调色（仅主线与裁定）。多线的身份由轨迹连续性给出，不靠色键。
4. **零图例，悬停即释**：现代 UI 的学习方式是悬停，不是图例墙。
5. **时间一根细轴**：起点与「今」两个刻度承担压缩时间的诚实声明；真实数字留在卡片。

## 语义映射（抽象化，去具象）

| 账本事实 | 图形（v2） | 数据源 |
|---|---|---|
| 研究线 | 轨迹线；**主线=唯一强调色、最粗** | worktree lanes |
| 派生宣告 | 分叉弧（只画宣告过的边） | 声明 parent 边 |
| 并入（merge） | 弧线汇回主线＋**汇流实点** | `status: adopted` |
| 死巷（有据的 No） | 轨迹**渐隐**＋末端 ✕（理由在悬停卡） | `status: failed` + closeReason |
| 工作节点 | 沿线小点（终局＞创造＞日常＞轻触；悬停=线名+动作+时刻） | worktree touches |
| 断言裁定 | **菱形**：实心=supported，空心=invalidated | claims |
| 宣告未开垦 | 虚线轮廓（可选层） | foraging 安静领地 |
| 当下 | 右侧细线 + 「今」 | derivedAt |

## 分阶段落地（不变）

- **V1**：现有 branch-flow 布局引擎换极简皮肤（去 8 色轮转、统一中性色+单强调色、
  断言菱形层）。纯客户端组合 `getWorktree + getForaging + getBrief`。
- **V2**：跨项目总览 + asOf 时间回放（派生是纯函数，任意时刻可重推）。
- **V3**：单图导出（SVG/PNG）。

## 诚实规则（进宪法）

1. 只画**宣告过的**结构，绝不推断。
2. 裁定记号只落在事实上，不评分、不喝彩。
3. 渐隐 = 无事件 ≠ 无前景。
4. 压缩刻度由时间轴声明，真实数字留在卡片。
5. 图零动词：它只说「你走过的路在这里」，永远不说「去这里挖」。
